本教程按“下一个问题从哪里来”排序。路线是为了学习而重建的因果路径，不是技术史的年代顺序。

```text
持久化记录
  -> 页与缓冲：以块为单位组织存储和 I/O
  -> 索引：减少定位数据所需读取的页
  -> 查询计划与执行器：把声明式 SQL 变成算子，再逐行产出结果
  -> WAL 与恢复：崩溃后恢复到合法状态
  -> 锁与隔离：并发操作仍满足事务语义
  -> MVCC：让读写在版本与快照上协作
  -> 单机引擎对照：理解 InnoDB 与 PostgreSQL 的具体取舍
  -> 复制：维护多个副本并定义确认语义
  -> 共识：故障和网络延迟下安全决定日志顺序
  -> 分片与分布式事务：将 SQL 扩展到多节点
  -> TiDB 路径：连接 SQL 层、PD、TiKV、Raft 与事务协议
  -> 从最初的持久化问题重建整个系统
```
